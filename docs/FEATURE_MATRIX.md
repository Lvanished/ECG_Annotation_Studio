# Feature implementation matrix

Implemented (backend test coverage): NPZ upload, calibrated numeric waveform retrieval, nine fixed tier names, point/interval CRUD, revision conflicts, audit snapshots, JSON/CSV annotations export, basic candidate R-peak detector.

Implemented in frontend source but unverified in browser: single-lead Canvas waveform, time-window controls, point/interval creation, tier marker selection, properties editing, AI candidate acceptance and rejection, file upload.

Not implemented: true 12-lead display, cross-lead synchronization, drag-to-adjust boundaries, custom tier persistence, undo/redo, versioned dataset snapshots, reference annotation import, segmentation masks, PyTorch training export, patient-aware split, clinical measurements, reviewer workflow, E2E browser tests, signal quality computation, Alembic migrations, configurable ontology, bulk operations.
