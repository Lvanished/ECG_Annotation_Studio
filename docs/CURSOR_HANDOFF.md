# Cursor handoff

Start with `README.md`, then `backend/app/main.py`, `frontend/src/main.tsx` and `docs/ANNOTATION_SCHEMA.md`. All nine tiers are currently fixed in frontend and backend. To add tiers, update both arrays; labels are free-form. To add WFDB dataset adapters, create separate modules that preserve annotation semantic differences (MIT-BIH beat symbols vs LUDB/QTDB wave boundaries). For AI models, add an inference service returning sample-index candidates, provenance and confidence, and persist predictions separately from manual labels. Priorities: (1) fix local proxy target configuration; (2) introduce Alembic migrations; (3) split frontend into components and add drag-to-edit/undo; (4) add verified PhysioNet reference adapters and metrics; (5) implement immutable export versions, masks, patient splits; (6) Playwright E2E and clinical expert validation. No hard-coded secret is required. Known limitations: README.
